On Linux (beta)
  • Extract it somewhere you own: tar xf @@LINUX_FILENAME@@ makes a folder called FTESurf.
  • Run ./ftesurf.sh. Engine errors go to stderr.log, a crash writes crash.log.
  • Momentum Mod Playtest has no Linux build: install it with Steam Play (Properties › Compatibility › a Proton version). FTESurf only reads its maps.
  • Native, Flatpak and Snap Steam are found automatically; for another drive, fs_steamlibs add /path/to/SteamLibrary then fs_restart.
  • Linux runs are not ranked during the beta.
Before you play

Alpha. The build is not code-signed, so SmartScreen warns the first time you run it. Physics fixes between builds can invalidate earlier times.

Upgrading from 0.1.9 or earlier? Delete ftesurf\ftesurf.cfg once, before you start the game: older builds saved Momentum Mod’s binds into it. That also resets your own settings, so note your sensitivity first.

Problems? Bring stderr.log or a screenshot to Discord.
