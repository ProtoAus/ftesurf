Setup and troubleshooting

Updates: The launcher asks before enabling update checks in a terminal. A first launch without a terminal skips the check. Change this in the game’s Updates pane.

Empty map list? Type fs_steamlibs in the console. To add another Steam library, use fs_steamlibs add D:\SteamLibrary, then fs_restart.

Alpha: The unsigned build may trigger a SmartScreen warning. Physics fixes can invalidate earlier times.

Upgrading from 0.1.9 or earlier? Delete ftesurf\ftesurf.cfg once, before you start the game: older builds saved Momentum Mod’s binds into it. That also resets your own settings, so note your sensitivity first.

Problems? Bring stderr.log or a screenshot to Discord.
