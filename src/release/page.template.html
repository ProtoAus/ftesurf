FTESURF

A competitive surf and bhop game on the FTEQW engine, reproducing Counter-Strike : Source and Momentum Mod movement — and playing the existing surf map library straight out of your own Steam installs.

Download

FTESurf ships no Valve or Momentum content — it reads your own installs at runtime. You need these three on Steam first.

  • Momentum Mod Playtest the map library — 1,308 maps
  • Counter-Strike: Source materials and models most surf maps use
  • Half-Life 2 skyboxes, dev textures, common props
  • CS:GO (legacy Source 1) and TF2 optional, mounted only for the maps that need them

After it downloads

  1. Extract the archive into a folder of its own. Nothing is written outside it, and there is no installer.
  2. Run ftesurf.bat. The engine takes its game folder from the working directory rather than from the .exe's location, and the batch file sets it — a shortcut pointing straight at ftesurf64.exe from elsewhere stops at a mod list.
  3. If the map browser is empty, or a mount says not found, type fs_steamlibs in the console. It prints where the engine looked and how each mount resolved. Add a library with fs_steamlibs add D:\SteamLibrary then fs_restart.
Alpha. The build is not code-signed, so SmartScreen will warn the first time you run it. Physics fixes between builds can invalidate previously recorded run times — this is a timing game whose ruleset is still moving.

What it is

Roughly 48,000 lines of QuakeC: a per-map timing system with zones, stages and bonuses; savelocs; ghosts and full run replays; a strafe-quality HUD you can lay out yourself; and a browser over 1,300+ maps with tiers, thumbnails and per-map asset resolution.

Movement is engine-side rather than QC-side, in a fork of FTEQW that adds the Source movement module and the hl2 plugin's .phy collision, VTF/VMT materials and static-prop lighting. Stock FTEQW will not run it; the engine is in the archive.
