Anti-Cheat

Every record, earned.

FTESurf doesn’t just trust a time. It checks the run that set it.

From run to record.

Three steps between crossing the line and the top of the board.

  1. Recorded.

    Every tick of a ranked run is written down as you play: where you were, how fast, where you looked and what you pressed.

  2. Replayed.

    Our server plays the recording back through the same physics. It has to reproduce exactly, and finish where the map’s own zones say it does.

  3. Ranked.

    A run that passes earns the Verified badge, and anyone can watch it, tick by tick.

Built in. Not bolted on.

Fairness is part of how FTESurf records a run, not an afterthought.

Three witnesses.

The server, the game and the engine each keep their own record of a run. A fake has to fool all three at once.

Locked rules.

Physics settings are fixed, and every recording carries the rules it was played under. A run under other rules can’t pass as ranked.

Demoted, never accused.

A run we can’t fully check still counts, on the community board. Ranked is for runs we can prove.

People decide.

Automated checks raise questions, not bans. A person reviews anything unusual.

Public by default.

Every ranked run can be watched by anyone, in game or on the web leaderboard. Records hold up in the open.

Safe to join.

We audit what a server is allowed to make your game do, and lock down what it shouldn’t.

Open source, closed playbook

Read the code. Not the playbook.

FTESurf’s code is open for anyone to read. How we spot cheating isn’t published — the details stay private, so they can’t be gamed.

Imported records from Momentum Mod and KSF live on boards of their own and never mix with ranked. A Momentum replay is only drawn on the exact map build it was set on.

Found a hole?

Don’t post it. Message the developer on Discord and it gets fixed before it spreads.
