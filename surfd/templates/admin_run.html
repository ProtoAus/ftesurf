    Receipt

    Stored similarity observations

    Historical store-only measurements, not a gate or accusation. Sources are not byte-bound here; no current-file guarantee or complete pair coverage is claimed. A skipped or missing comparison is not a low score.

    Key

    First key wins: a player's first signing key is theirs. new is another key for this player, shared a key that first signed for someone else, unsigned a run with no signed receipt from a player who has signed before. A shared machine and a reinstall look the same as an impostor, so this is shown here and nowhere else. Accepting a key clears it for good; accepting unsigned runs covers only those submitted so far. “Not this player's key” keeps the flag and hands the first-key slot to the player's next key — use it on an impostor's key, at the run that set it. Whether a player cheats is the run review's call, not this card's.
