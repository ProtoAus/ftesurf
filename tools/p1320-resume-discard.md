# P1320 - preserve paused slots until discard is authorized

## Scope

Server QC only. All offered-slot discard callers now use the existing ownership
predicate immediately before modifying saved files. Unavailable metadata keeps
the files and offer intact. Fresh-running, finished and explicit manual paths
share this gate; repeated automatic refusals do not repeat chat every frame.
Authorization is re-evaluated, not cached in the notification state.

Existing matching-key, unkeyed legacy, account-off and guid-mode policy remains.
Authorized cleanup still archives a recording that backs posted stages before
removing its slot. No movement, ranking, evidence format, capture, native API,
engine pin/tag, Build number, account protocol or consent change.
