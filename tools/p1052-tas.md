# P1052 — explicit TAS practice sessions

Requested 26 Oct 2026: staged TAS editor and contributor plan, and start implementation.
Full plan: [plan-tas.md](plan-tas.md). This patch is stage 1, not the completed editor.

## Implemented

Console `tas on`, `tas off`, `tas status`, `tas speed 0.1..1`. Existing `host_timescale`
remains available. Slow speed reuses P954's per-player pacing, input protocol/prediction
and threaded-input guards. Turning TAS off restores speed but not human eligibility.

TF_TAS bit22 records assisted ancestry, always with the practice/cheat safety flags,
including run_class 0. Ordinary saves, snapshots, no-prefix rewind placements, demoted
saves and exact retry retain it. Loading a TAS save raises the session latch. Native
observe/join retains ancestry but resets controls; actual fresh connections/maps reset
session controls and may load the ancestry again. Replay/view save requests can raise
TAS restrictions; this is not a service-observed capture assertion or an authorship proof.

The existing local nonranked slot is the retention path; labels identify TAS in results,
replays and banners. The recording reader validates the companion flags. Backend admission
and certification independently refuse TAS, including a TAS-only flag word. No TAS board.

The old gift/mirror formats cannot preserve ancestry. TAS/unreadable selected-save gifts
are refused, TAS/unknown lobby rows are omitted from mirroring, and local TAS files take
the protected-file path instead of uploading. The existing incomplete-list guards block
deletions on affected sync lists. Normal position-only sharing/sync remains the old path.
Full ancestry-preserving project transfer is a later stage, not silently downgraded here.

## Predictions and controls

- Clean saves remain unmarked; valid human/segmented classification remains unchanged.
- TAS remains excluded with run_class 0 as well as 1 and with missing companion flags.
- Off, older clean saves, native observe/join and retry cannot lower retained ancestry.
- A genuinely fresh connection is not permanently poisoned; loading TAS marks it again.
- A real timed TAS run must act, record and retain its category; silence is not a pass.
- Subject adds no compiler warnings; reader corpus faults must not increase.

## Limits and remaining work

No frame advance, input editor, optimizer, cryptographic contributor chain or ranked TAS
submission exists yet. Physics replay/signatures do not prove human manual input. No
new native movement semantics, engine commit/tag pin, recorder grammar version or qcbuild.
Demotion/transfer protections have source review, not a new exhaustive fleet sync campaign.
Visual feel and replay/banner presentation require the small owner check in lextest.md.
