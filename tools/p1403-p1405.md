## P1404: replay a report on a rig

- `pe_replay <file>` / cvar `pe_replay_auto` (csprogs, serverinfo *cheats ON only, rechecked per frame):
  each command carries its row's angles, moves, buttons and duration (input_timelength). `pe_state`
  (qwprogs, sv_cheats 1 only, at command and at apply): SV_SetPosSelf, then the recorded velocity and
  name, before the requested command. Warp ops are not replayed.
- tools/prederr_replay.py REPORT --rigroot DIR --progs BUILD: start = worst - max(60, settle+48), state
  from the ack rows when present, durations from the lobby's rows; verdicts REPRODUCED [(smaller)]
  [(expected: <rule>)] / NOT REPRODUCED / CANNOT TELL, each needing the server path to match the report's
  before and at the worst command. Six synthetic cases (gradetest2.py) give the intended verdicts.
- Falsifier: surf_perennial 073418 against a build with P1394 compiled out: REPRODUCED 3840.0 at exactly
  command 5247 (path 0.2 units / 0.4 u/s); the P1394 build NOT REPRODUCED on the same inputs. Two runs of
  one replay bit-identical once durations were forced (a 50 ms rig hitch had moved one 3 ticks).
