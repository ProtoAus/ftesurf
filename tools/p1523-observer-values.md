# P1523 - Parsed observer records are not necessarily measurements

## Acting defect and bounded change

Six numeric view terms and two raw-annotation terms could carry NaN through the
reader's arithmetic. All eight controlled cases retained receipt content OK;
angle/join counters and healthy-zero input totals were not proof of usable data.
The positive finite view/raw controls actually judged and joined19 frames, while
malformed-annotation/finite-contradiction controls faulted and a controller profile
remained BLIND. Actual captured digests were checked without reopening; signature
status was unchanged, NOT verified by these content tests.

Require finite numeric raw/view terms. Descriptive parsed view-record counts
remain distinct from comparative metrics. An unusable view can poison the next
baseline: both-axis identity uses existing unsupported-profile exclusions, and
the raw-target join is unavailable. An unusable raw annotation is not an absent
annotation or a claim that quantities are equal: withhold its join, while valid
independent view arithmetic can still act. Existing malformed time/width/numeric
observer rows also cannot retain surviving partial comparisons.

These are data-quality faults, not angle/count accusations. Existing receipt
handling withholds unproved input totals without changing digest/signature
status. Valid legacy optional keyboard terms are None, not malformed data. No
new wire/schema, capture, numerical cutoff, policy, ranking, regrading, native
code or Build. Native pin/tag remain c433ba70b/patch-1521; QC Build stays89.
