# P923 — recording continuation and bounded native compatibility

## Scope

New ordinary recordings declare recording-relative mouse-counter totals (REC14).
Current optional native-held recordings use REC15; readers keep REC1–13's original
clock/counter meaning. Recovery of an unsuccessful selected source is private,
no-replace and identity-checked. Existing qualification, completion, data-access
and retention policy still apply; no leaderboard result follows from recovery.
The optional detailed held collector remains opt-in, not enabled by this patch.

The bounded native replay profile is explicitly reviewed for Source mover11.
Its fixed context/initial schemas remain unchanged. New carried water-assist
state must be zero independently at capture, native context packing, model
boundaries and ordinary-seed comparison. An unsupported context stays unsupported;
this is not general held-world coverage, device provenance or proof of human play.
Old/future mover contexts are not silently promoted into this current-only profile.
